# Apexify — Engineering Digital Excellence

A modern, high-performance website and design system for **Apexify**, a software engineering and digital product studio specializing in bespoke web applications, enterprise software architectures, and digital transformation.

## 🚀 Features

- **Dynamic & Colorful UI/UX**: Custom color-coded system identities, luminous ambient glow orbs, glassmorphism navigation, and responsive typography.
- **Enterprise-Grade Pages**:
  - `home.html`: Studio overview, capability grid, featured projects, process pipeline, and testimonials.
  - `services.html`: Modular service pricing cards with customized visual identities and interactive estimation modals.
  - `process.html`: 6-stage engineering lifecycle with visual roadmap connections and delivery checkpoints.
  - `why-us.html`: Engineering differentiators, verified performance metrics, and client satisfaction SLAs.
  - `solution.html`: Technical architectures, distributed systems, deployment topologies, and performance benchmarks.
  - `our_work.html`: Interactive portfolio with category filtering and case studies.
  - `contacts.html`: Responsive inquiry portal, onboarding roadmap, and SLA guarantees.
  - `privacy-policy.html` & `terms-and-conditions.html`: Compliance and legal terms.
- **Tailwind CSS v3**: Pre-configured build pipeline with custom theme tokens, typography, and utility classes.

## 🛠️ Tech Stack

- **HTML5 & Vanilla JavaScript**: Zero runtime bloat, accessible semantic markup, and instant load times.
- **Tailwind CSS**: Modern CSS utility architecture.
- **Google Fonts**: Outfit & Plus Jakarta Sans.
- **Google Material Symbols**: Clean modern iconography.

## 📦 Setup & Development

To install dependencies and build styles:

```bash
# Install dependencies
npm install

# Build CSS for production
npm run build:css

# Watch for CSS changes during development
npm run watch:css
```
